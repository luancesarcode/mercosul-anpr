# Mídia de demonstração

Este espaço foi criado sem adicionar conteúdo visual.

```text
docs/media/
  images/   capturas e comparações futuras
  videos/   demonstrações futuras em vídeo
  gifs/     demonstrações futuras em GIF
```

Antes de publicar uma mídia:

1. Use somente placas fictícias ou dados com autorização documentada.
2. Remova localização, pessoas, rostos e metadados desnecessários.
3. Prefira um arquivo curto e otimizado; não aumente o clone do repositório sem necessidade.
4. Adicione texto alternativo ou uma transcrição.
5. Registre origem e licença.
